# Unified Assessment Platform

##  Project Overview

A full-stack web application developed to manage and automate assessments. It allows users to take tests, evaluate performance, and view results through an interactive dashboard.

##  Features

* User authentication (login/signup)
* Online test/assessment system
* Automated scoring
* Dashboard for performance analysis
* Admin panel for managing assessments

##  Tech Stack

* Frontend: React.js
* Backend: Node.js / Express
* Database: MongoDB (or mention yours)
* Tools: GitHub, Postman

## How to Run the Project

### 1. Clone the repository

git clone https://github.com/your-username/your-repo-name.git

### 2. Run Backend

cd backend
npm install
npm start

### 3. Run Frontend

cd frontend
npm install
npm start
